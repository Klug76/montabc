# montabc

[EN](README.md) | **RU**

Переписанная на чистом C версия [montab](https://github.com/faxenoff/montab) —
боковая панель-таскбар для Windows с **постоянно видимыми живыми превью**
всех открытых окон. Полдюжины терминалов в обычном таскбаре выглядят
одинаково — здесь достаточно взглянуть на панель, чтобы найти нужное. Одна
панель на монитор, каждая показывает только окна своего монитора. Доковится к
левому или правому краю и резервирует рабочую область — максимизированные
окна никогда не перекрывают панель. Превью обновляются в реальном времени
через DWM-композитор, почти не тратя ресурсов.

Порт сохраняет поведение и возможности оригинала, но полностью убирает .NET:
чистый C17 поверх WinAPI, а Release-сборка — zero-CRT exe размером
**~39 КБ**, импортирующий только шесть системных DLL (никаких рантаймов и
зависимостей).

## Возможности

- Панель на каждом мониторе, только окна этого монитора.
- Живые DWM-превью с сохранением пропорций; активное окно выделено рамкой.
- Две секции: живые превью сверху, свёрнутые окна снизу — компактные полоски
  с иконкой и заголовком.
- Клик — переключение, двойной клик — свернуть, ✕ — закрыть, ПКМ — свернуть,
  drag — переставить, Ctrl+колесо — зум ×1–5, hover-лупа, скроллбар-оверлей.
- Перетаскивание панели — смена края или перенос на другой монитор; тяните
  внутренний край, чтобы менять ширину (3–50% ширины монитора).
- Иконка в трее: скрыть/показать панели, меню по мониторам, автозапуск.
- Настройки per-монитор в `%APPDATA%\montabc\settings.ini`.
- Интерфейс RU/EN, следует языку системы.

Полная таблица управления и заметка о «заморозке» превью Chromium-браузеров —
в [README оригинала](https://github.com/faxenoff/montab/blob/main/README_RU.md).

## Отличия от оригинала

Кратко; оригинал написан на C#/.NET 11 (NativeAOT):

- **Zero-CRT-сборка**: один exe ~39 КБ против ~2,1 МБ; импортирует только
  6 системных DLL, .NET не нужен.
- **Ресайз без мерцания**: полные переговоры с AppBar (`ABM_QUERYPOS`/`SETPOS`)
  выполняются один раз на отпускание кнопки; во время тяги — лёгкий
  `SetWindowPos` с принудительной перерисовкой, максимизированные окна не
  прыгают и не мерцают.
- **Архитектура**: отдельное скрытое host-окно вместо роли окна трея;
  статический массив на 512 окон вместо GC-коллекций.
- **Настройки**: `%APPDATA%\montabc\settings.ini` (INI) — несовместимы с
  `settings.json` оригинала, миграции нет.
- **Сборка под Windows 7**: дополнительная конфигурация `ReleaseWin7`
  (toolset v143, `WINVER 0x0601`); оригинал поддерживает только Windows 10
  1809+.
- Всё остальное — трекинг/фильтрация окон, раскладка, превью, интерактив,
  локализация — сознательный порт 1:1.

Обе версии могут работать параллельно (разные мьютекс, классы окон и ключ
автозапуска в реестре).

## Загрузка

Готовые бинарники — на странице
[Releases](https://github.com/Klug76/montabc/releases):

- `montabc-x64.exe` — Windows 10 1809+ (x64)
- `montabc-win7-x64.exe` — Windows 7+ (x64)

Пуш тега `v*` запускает GitHub Actions, который собирает обе конфигурации и
публикует релиз автоматически.

## Сборка

Нужна Visual Studio 2026 с рабочей нагрузкой C++ (MSVC v145; конфигурация
Win7 использует входящий в неё toolset v143) и MSBuild:

```sh
msbuild montabc.sln -m -p:Configuration=Release -p:Platform=x64
```

Результат: `x64\Release\montabc.exe`. Конфигурация `Debug` — обычная сборка с
CRT для отладки; `ReleaseWin7` даёт совместимую с Windows 7 сборку в
`x64\ReleaseWin7\`.

Если установлены компоненты «C++ Clang tools for Windows», тот же проект
собирается через clang-cl — exe получается ещё на несколько КБ меньше (~36 КБ):

```sh
msbuild montabc.sln -m -p:Configuration=Release -p:Platform=x64 -p:PlatformToolset=ClangCL
```
